    Control Panel Icons

    Reset
    Press the Reset button to zero the weight scale.
    A long press, while at the home position, will never night light setting mode.
    If already cycling, press Reset to pause a cycle, press again to cancel a cycle.
    If already cycling, a long press will reset the cat sensor weight scale.
    Power
    Press the power button to turn the robot ON or OFF.
    Empty
    Press the Empty button to start an empty cycle.
    A long press, while at the home position, will enter the wait time setting mode.
    If already cycling, press Empty to pause.
    Cycle
    Press the Cycle button to start a clean cycle.
    A long press while at the home position, will enter sleep mode.
    If already cycling, press Empty to pause, press again to resume a cycle.
    Connect
    Press the Connect button to turn the WiFi ON or OFF.
    A long press, while at the home position, will initiate the onboarding process.
    What do the lights mean?
    Solid Yellow
    Robot paused during cycle.
    Press Cycle button to continue cycling.
    Round Robin Yellow Yellow light moving with the rotation of the globe.
    Robot cycling.
    Solid Red
    Cat detected and cycle delay countdown initiated.
    No action required or press Reset to cancel timing.
    Solid Blue
    Robot ready and connected.
    Wifi Flashing Yellow
    Robot in WiFi onboarding mode.
    Flashing Blue
    Waste drawer full.
    Solid Purple
    Sleep mode enabled, within specified sleep time.
