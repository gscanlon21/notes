# Reference 

**Subscript**
`_{}`
: > - > - V_{0}
  >   > - $$V_0$$

**Fraction**
`\frac{}{}`
: > - > - \frac{1}{2}
  >   > - $$\frac{1}{2}$$

**Horizontal Space**
`\hspace{}`
: > - > - \hspace{2mm}
  >   > - $$\hspace{2mm}$$
