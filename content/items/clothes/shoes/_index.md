# Terminology

**Heel-to-Toe Drop**
: Refers to the height of the heel compared to the height of the toes.
: How much the heel is elevated in shoes.



# Overview

**Size**
: US Men's 12

**Style**
: Wide shoes — Need room for the toes to spread.
