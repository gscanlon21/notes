# Overview

**What is a Measure?**
: A measure is a reusable calculation.


# Samples

**Total Applications**
: `Total Applications = COUNTROWS('table_name')`

**Distinct Applications**
: `Total Applications = DISTINCTCOUNT('table_name'[Column Name])`
