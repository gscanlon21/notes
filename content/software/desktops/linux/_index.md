# Directory Structure

**/boot**
: Boot files

**/root**
: Root Home Directory

**/home**
: Personal Data

**/media**
: Removable Media

**/bin**
: Binaries

## Program Executables

**/lib**
: Shared Libraries

**/usr**
: User

## User Specific Binaries and Program Data

**/var**
: Variable Data Files

**/dev**
: Device

## Device Files

**/dev/null**
: Can be piped to to destroy any data

**/etc**
: System configuration files
: **/etc/hosts**
  : Hostname mapping file
: **/tmp**
  : Temporary Files
