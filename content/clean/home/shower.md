# Limescale

**Overview**
: Limescale is acidic and dissolves in an acidic solution.

**Dawn/Vinegar**
: Mix _Dawn Dish Soap_ and _Vinegar_ together in a 1:1 ratio.
: - > - > Spray it on and very lightly spread it all over the surface with a cloth.
    > - > Let it set for a couple of hours. 
    > - > Spray more on and let it set for a bit. 
    > - > Then with warm water, wet cloth wipe it off and rinse. It should work. If not repeat by spraying more and letting set for half an hour.
