# Browser Extensions

## uBlock Origin

### Filter Syntax

`@@`
_Allow Rule_
: Negates another filter.

`||`
_Domain Match_
: Means the root domain, including subdomain prefixes.

`^`
_Separator Character_
: Matches a URL separator such as /, ?, &, =, :, or the end of the URL.
