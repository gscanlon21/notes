# Overview

{% <table header="Optimum ranges for water quality parameters to determine suitability of water sources for hydroponic cropping systems[^1]" class="small"> %}
| Parameter              | Optimum range               |
|------------------------|-----------------------------|
| pH                     | 5.5–7                       |
| EC (dS/m)              | 0.2–0.8                     |
| Alkalinity             | 40–160 ppm CaCO3 equivalent |
| Dissolved oxygen       | >6 ppm                      |
| Total suspended solids | <30 ppm                     |
{% </table> %}

{% <table header="Problematic Ions[^1]" footer="1 ppm is the same as 1 mg/L (1 mg of the element in 1 liter of water)" class="small"> %}
| Parameter | Optimum range |
|-----------|---------------|
| Sodium    | <50 ppm       |
| Chlorine  | <70 ppm       |
| Sulfates  | <90 ppm       |
| Boron     | <0.5 ppm      |
| Fluor     | <1 ppm        |
| Calcium   | <150 ppm      |
| Magnesium | <75 ppm       |
| Iron      | <1 ppm        |
| Manganese | <1 ppm        |
{% </table> %}
